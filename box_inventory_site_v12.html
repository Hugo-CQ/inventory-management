导出 / 数据处理

导出 Excel、备份 JSON、恢复 JSON 或清空全部本地数据。

数据默认保存在当前浏览器 localStorage。换电脑或清理浏览器缓存会丢失，请定期导出 Excel 或 JSON 备份。

编辑箱内物料记录

在弹窗内直接修改已录入记录，保存后会即时更新右侧明细表，不会影响左侧新增物料表单。

编辑箱子/货架记录

在弹窗内修改箱子编码或货架号。若箱子编码变更，已绑定的箱内物料会同步更新到新箱号。
